This is my current on-going fandom survey fandom map! All the data was gathered by me and checked by friends from multiple different fandoms. It is not intended to enforce or restrict where players should sit or gather.

## ℹ️ Overview

- Pins on the map allow you to hover to see what fandoms usually gather in that location
- You can search for fandoms
- Hovering over fandom names will also highlight the pin associated
